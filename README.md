# 🏸 MyBad ก๊วนแบด

เว็บแอปสำหรับก๊วนแบดมินตันในกลุ่มเพื่อน ใช้บนมือถือเป็นหลัก

- **สุ่มคู่หูประจำสัปดาห์** สุ่มครั้งเดียวตอนสร้างนัด แล้วตีกับคู่หูคนนี้ทั้งวัน ระบบจะเลี่ยงคู่ที่เคยจับกันในสัปดาห์ก่อนๆ ให้ได้คู่ใหม่เรื่อยๆ (ถ้าคนมาเป็นเลขคี่ คนที่เป็นเศษจะลงพร้อม "ตัวเติม" ที่ระบบเสนอชื่อให้ และสลับคนเป็นเศษทุกสัปดาห์)
- **ล็อกคู่** กด 🔓 ที่คู่ไหน หรือเลือก 2 คนให้เป็นคู่กันเอง คู่ที่ล็อกจะไม่ถูกสุ่มใหม่ (เฉพาะนัดนั้น)
- **คิวลงสนาม (ชนะอยู่ต่อ สูงสุด 2 เกม)** เริ่มจากคู่ 1 vs คู่ 2 แล้วกด "เริ่มเกมถัดไป" ระบบเรียกคู่ตามคิวให้เอง ชนะอยู่ต่อ แพ้ไปต่อท้ายคิว ชนะ 2 ติดต้องออก ไม่มียามสนาม (กติกาอยู่ใน `src/lib/queue.ts`)
- **นับแต้มบนมือถือ** แตะครึ่งจอของทีมที่ได้แต้ม ระบบบันทึกทุกแต้มทันที คะแนนไม่หาย และบอกด้วยว่าใครเสิร์ฟ ยืนฝั่งไหน
- **ตารางอันดับ** ดูได้ทั้งของวันนั้นและสถิติรวมทุกนัด

เทคโนโลยีที่ใช้: Next.js 16 (App Router), React 19, Tailwind CSS 4, Prisma 7 และ PostgreSQL (Neon)

## 🚀 เริ่มต้นใช้งาน (รันบนเครื่องตัวเอง)

### 1. ติดตั้ง

```bash
npm install
```

### 2. สร้างฐานข้อมูลฟรีที่ Neon

1. สมัครที่ <https://neon.tech> แล้วกด **Create project** (เลือก Region เป็น Singapore จะเร็วสุดสำหรับคนไทย)
2. กด **Connect** แล้วคัดลอก Connection string ที่หน้าตาประมาณ `postgresql://...neon.tech/neondb?sslmode=require`
3. คัดลอกไฟล์ `.env.example` ไปเป็น `.env` แล้ววาง Connection string ที่บรรทัด `DATABASE_URL=`

### 3. สร้างตารางในฐานข้อมูล และใส่ข้อมูลตัวอย่าง

```bash
npm run db:migrate    # สร้างตารางตาม prisma/schema.prisma
npm run db:seed       # (ไม่บังคับ) เพิ่มผู้เล่นตัวอย่าง 8 คน
```

### 4. รัน

```bash
npm run dev           # แล้วเปิด http://localhost:3000
```

**อยากลองบนมือถือ?** ให้มือถือกับคอมต่อ Wi-Fi เดียวกัน แล้วรัน `npm run dev:phone`
จากนั้นเปิดลิงก์ `http://<IP ของคอม>:3000` ในมือถือ (ดู IP ได้จากคำสั่ง `ipconfig`)

## 🌐 Deploy ขึ้นเว็บจริง (ฟรี) ด้วย Vercel

1. Push โค้ดขึ้น GitHub
2. ไปที่ <https://vercel.com> → **Add New → Project** → เลือก repo นี้
3. ไปที่ **Storage → Create Database → Neon** แล้วเชื่อมกับโปรเจกต์ (Vercel จะใส่ `DATABASE_URL` ให้เอง)
   หรือถ้ามีฐานข้อมูล Neon อยู่แล้ว ให้ไปใส่ `DATABASE_URL` เองที่ **Settings → Environment Variables**
4. กด **Deploy** แล้วรอได้ลิงก์ `xxx.vercel.app` ส่งให้เพื่อนได้เลย

> ตอน deploy Vercel จะรันคำสั่ง `vercel-build` ใน `package.json` ซึ่งสร้าง/อัปเดตตารางในฐานข้อมูลให้อัตโนมัติ (`prisma migrate deploy`)

### หลักการแบ่งโฟลเดอร์ (จำง่ายๆ)

| โฟลเดอร์ | ทำหน้าที่ | ตัวอย่าง |
|---|---|---|
| `app/` | **แสดงผล** ดึงข้อมูลจากฐานข้อมูลมาโชว์ | หน้ารายชื่อผู้เล่น |
| `actions/` | **เปลี่ยนแปลงข้อมูล** เมื่อผู้ใช้กดปุ่มหรือส่งฟอร์ม | กดปุ่ม "เพิ่ม" ผู้เล่น |

| `lib/` | **สมองของระบบ** เป็นฟังก์ชันล้วน รับค่าเข้าแล้วคืนค่าออก | สุ่มคู่, เช็กว่าใครชนะ |

## 📚 ลำดับการอ่านโค้ด สำหรับมือใหม่

1. **`prisma/schema.prisma`** ดูว่าเก็บข้อมูลอะไรบ้าง (ผู้เล่น, นัด, เกม)
2. **`src/lib/scoring.ts`** ไฟล์สั้นและง่ายที่สุด เป็นกติกาแบดล้วนๆ
3. **`src/app/players/page.tsx`** หน้าแรกที่ควรดู เห็นการดึงข้อมูลจาก DB มาแสดงแบบตรงไปตรงมา
4. **`src/actions/players.ts`** + **`src/components/AddPlayerForm.tsx`** ดูว่ากดปุ่มแล้วข้อมูลเข้า DB ได้ยังไง
5. **`src/lib/pairing.ts`** อัลกอริทึมสุ่มคู่ มีคำอธิบายแนวคิดอยู่ด้านบนไฟล์
6. **`src/actions/sessions.ts`** ดูว่าเอาข้อมูลจาก DB ส่งให้ `pairing.ts` คิด แล้วบันทึกผลกลับยังไง (ฟังก์ชัน `createTeams`)
7. **`src/components/Scoreboard.tsx`** ตัวอย่าง Client Component ที่มี state, ปุ่มกด และการบันทึกแบบทันที

### คำศัพท์ที่จะเจอบ่อย

- **Server Component** (ค่าเริ่มต้นของทุกไฟล์ใน `app/`): ทำงานบน server เรียกฐานข้อมูลได้ตรงๆ ด้วย `await db...`
- **Client Component** (ไฟล์ที่ขึ้นต้นด้วย `"use client"`): ทำงานในเบราว์เซอร์ ใช้ `useState`, `onClick` ได้ แต่เรียก DB ตรงๆ ไม่ได้
- **Server Action** (ไฟล์ที่ขึ้นต้นด้วย `"use server"`): ฟังก์ชันบน server ที่หน้าเว็บเรียกใช้ได้เหมือนฟังก์ชันธรรมดา ใช้แก้ข้อมูล
- **`refresh()`**: สั่งให้หน้าเว็บโหลดข้อมูลใหม่หลังแก้ข้อมูล
- **`redirect()`**: พาไปหน้าอื่นหลังทำงานเสร็จ

|---|---|
| `npm run dev` | รันเว็บตอนพัฒนา (เซฟไฟล์แล้วหน้าเว็บอัปเดตเอง) |

## ⚠️ ข้อควรรู้

- ระบบนี้ยังไม่มีการ login ใครมีลิงก์ก็แก้ข้อมูลได้ เหมาะกับใช้ในกลุ่มเพื่อน อย่าแชร์ลิงก์ในที่สาธารณะ
- มีคนมาสายก็ได้ ติ๊กชื่อเพิ่มใน "คนที่มา" แล้วกด "สุ่มคู่หูใหม่" ได้เลย เกมที่ตีจบไปแล้วยังอยู่ครบ (แต่ต้องไม่มีเกมที่กำลังตีหรือรอคิวค้างอยู่)
- ระบบดูประวัติคู่หูย้อนหลัง 6 นัด ถ้าก๊วนคนน้อย อาจเริ่มได้คู่ซ้ำหลังผ่านไปหลายสัปดาห์ ซึ่งเป็นเรื่องปกติ
- อยากให้ดูประวัติคู่หูย้อนหลังมากหรือน้อยกว่านี้ ให้แก้ตัวเลข `HISTORY_WEEKS` ด้านบนไฟล์ `src/actions/sessions.ts`
